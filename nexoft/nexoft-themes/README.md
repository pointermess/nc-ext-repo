# Nexoft Themes

A collection of beautiful, hand-crafted color themes for NexCODE IDE.

## Included Themes

### Dark Themes

| Theme | Description |
|-------|-------------|
| **Dracula** | The famous dark theme with purple accents |
| **Monokai Pro** | Classic Monokai with refined, warm colors |
| **Nord** | Arctic, north-bluish color palette |
| **One Dark Pro** | Inspired by Atom's iconic One Dark theme |
| **Solarized Dark** | Ethan Schoonover's precision color scheme (dark) |
| **Catppuccin Mocha** | Soothing pastel theme (darkest variant) |

### Light Themes

| Theme | Description |
|-------|-------------|
| **Solarized Light** | Ethan Schoonover's precision color scheme (light) |
| **Catppuccin Latte** | Soothing pastel theme (light variant) |

## Usage

### Via Settings

1. Open **Settings** (Ctrl+,)
2. Go to **Appearance**
3. Select any Nexoft theme from the theme picker

### Via Command Palette

Open the Command Palette (Ctrl+Shift+P) and type:

- `Apply Dracula Theme`
- `Apply Monokai Pro Theme`
- `Apply Nord Theme`
- `Apply One Dark Pro Theme`
- `Apply Solarized Dark Theme`
- `Apply Solarized Light Theme`
- `Apply Catppuccin Mocha Theme`
- `Apply Catppuccin Latte Theme`

## Theme Previews

### Dracula
A dark theme with purple and pink accents, perfect for late-night coding sessions.

### Monokai Pro
The refined version of the classic Monokai theme, featuring warm yellows, pinks, and greens.

### Nord
An arctic, north-bluish color palette inspired by the colors of the Nordic wilderness.

### One Dark Pro
Based on Atom's iconic One Dark theme, featuring a modern blue-accented dark interface.

### Solarized
Ethan Schoonover's legendary color scheme, available in both dark and light variants with carefully crafted color relationships.

### Catppuccin
A community-driven soothing pastel theme, available in Mocha (dark) and Latte (light) variants.
